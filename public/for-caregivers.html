Why it fits

Memory with dignity built in.

  • ✓It only knows what you tell it. Max never watches, listens in, or guesses. Deliberate memory — a principle we call "tell, don't observe."
  • ✓Private by architecture. Personal memories live on the phone they were spoken into — not in a cloud database. No account, no profile, nothing to breach.
  • ✓Codes and keys, behind a lock. Door codes, lockbox combinations, alarm PINs — entered privately, never spoken aloud, revealed only on screen when asked.
  • ✓Patient, every single time. The same question can be asked twenty times and receive the same kind answer — that's not a burden to Max.
  • ✓Simple to hand over. No setup wizard, no account creation — install, talk. Reminders and appointments still ring through the phone's own apps.

Max is a memory helper, not a medical device — it doesn't diagnose, treat, or make care decisions.
